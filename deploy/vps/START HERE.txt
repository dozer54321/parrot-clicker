PARROT CLICKER
==============

Hostname: parrot.yourmomon.top

Same hosting as Momon and Take-Home. The app does not grab ports 80 or 443.
It listens on 127.0.0.1:3060 and is added to the Caddy you already run.

  3010  Take-Home
  3060  Parrot Clicker
  3080  Momon
  3090  Eye tracker

Point DNS (A record) for parrot.yourmomon.top at this machine first.

Install — no git, no GitHub username. Rebuilds the app and checks the site:

  sudo apt-get update && sudo apt-get install -y curl
  curl -fsSL -o /tmp/parrot-install.sh https://raw.githubusercontent.com/dozer54321/parrot-clicker/main/deploy/vps/bootstrap.sh
  sudo bash /tmp/parrot-install.sh

It is done only when https://parrot.yourmomon.top returns the game.
A certificate with no app behind it is a 502. This install does not leave it that way.

www is not included. www.parrot.yourmomon.top has no DNS record.
